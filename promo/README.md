# Agensi promo for the Community Edition

A 40-second launch trailer (1920 × 1080, 30 fps) for the free Create Voiced Ad Community Edition, and
the demo ad it shows: **Quietdesk**, a fictional product, made with this repository's own
`templates/` (copied to `src/demo/` and adapted, as the skill asks Claude to do).

| File | What |
|---|---|
| `../demos/agensi-community-promo-16x9.mp4` | The promo (rendered, not committed: see "Render") |
| `../demos/agensi-community-promo-16x9.en.srt` | English subtitles, from the narration timestamps |
| `../demos/agensi-community-promo-thumbnail.png` | Listing thumbnail (1920 × 1080) |
| `src/promo/` | Promo composition, timeline, narration text, thumbnail |
| `src/demo/` | The Quietdesk ad: the Community templates, adapted (voiceover, theme, acting, panels, screens) |
| `public/logo.png` | The official logo, unchanged |
| `public/{promo,demo}/voiceover/` | ElevenLabs narration (MP3) — committed so renders need no new generation |
| `scripts/` | Voiceover (with cost gate), music and sound effects, render with loudness normalization, SRT |
| `docs/` | Storyboard, voiceover script, validation report |

## Render

Requirements: Node.js 22+, pnpm, FFmpeg on the PATH (loudness normalization), network on first
render (Remotion downloads its browser; Google Fonts are fetched).

```bash
cd promo
pnpm install
pnpm music          # synthesizes the music beds and sound effects (MIT, generated by code)
pnpm render:demo    # out/quietdesk-demo-16x9.mp4
pnpm render:promo   # ../demos/agensi-community-promo-16x9.mp4, normalized to -14 LUFS
pnpm srt            # ../demos/agensi-community-promo-16x9.en.srt
pnpm thumbnail      # ../demos/agensi-community-promo-thumbnail.png
```

The narration is already generated. Changing a line regenerates only that line, through ElevenLabs
(paid, with your own key): see `docs/voiceover-script.md`.

## Differences from the Community template

The demo follows the template with these changes, documented in the code: English text and voice;
music and sound effects synthesized locally instead of ElevenLabs Music / Sound Effects (to avoid
paid generation); the voiceover script prints the cost and requires `--approve` and `--max-credits`;
no `language_code` sent to `eleven_multilingual_v2`; Mbeng-specific content removed.
